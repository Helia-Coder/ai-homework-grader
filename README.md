# 🤖 智阅·AI 智能作业批改与学情分析系统

## 📖 1. 项目介绍

本项目针对中学数理化作业中“手写解答过程难批改、分步得分难细化、错因数据难沉淀”的痛点，打造了一款基于多模态大模型的「AI 初筛 + 教师终审」人机协同批改系统。

**核心功能：**
- **多模态切题与批改**：学生拍照上传，AI 自动识别手写公式与文本，按“大题-小问-步骤”三级结构返回批改结果。
- **防幻觉机制**：引入前后端双重算分校验（Deterministic Function Calling），彻底解决大模型步骤分相加不守恒的痛点。
- **人机协同复核**：教师端支持一键修改分步得分、联动重算大题总分、防抖自动保存，并留痕标记。
- **学情数据画像**：基于 NLP 关键词聚类，自动生成班级高频错因饼图与个人错因画像，助力精准教学。

## 🛠️ 2. 技术架构

本项目采用 **Next.js 全栈单体架构**，前后端同仓，降低部署复杂度。

- **前端表现层**：Next.js 14 (App Router) + React 18 + Tailwind CSS + Recharts (可视化) + KaTeX (公式渲染)
- **后端接口层**：Next.js Route Handlers (RESTful API)
- **AI 能力层**：阿里云百炼 DashScope (Qwen-VL 多模态大模型) + Prompt Engineering (严格 JSON 约束)
- **数据持久层**：MySQL + Prisma ORM (级联表设计，保障事务一致性)
- **安全鉴权**：JWT (JSON Web Token) + HttpOnly Cookie 实现 RBAC 角色权限控制

### 🚀 安装运行指南

### 1. 前置环境要求
在开始之前，请确保你的电脑上已安装并启动了以下环境：
- **Node.js** 18.0 或更高版本（推荐 v20+）
- **MySQL** 8.0 或更高版本（请确保本地 MySQL 服务已启动）
- **包管理器**：npm（随 Node.js 自动安装）
